# 커리어마이징 콘텐츠 검수

초안(카피 텍스트, 렌더 스펙 JSON, PNG, Figma 링크)을 받아 **운영 문서의 기준 그대로** 점검한다. 기준 문서는 `../careermizing-content/references/`에 있다. 평가는 "좋다/나쁘다"가 아니라 **어느 장의 어느 문장이 어떤 규칙에 걸리고 어떻게 고칠지**로 쓴다.

## 순서

1. 유형을 판정하고(취준팁·면접팁·정보성 / 프로모션 / 기업별 / 기능 홍보) 해당 `content-types/*.md`와 `brand-voice.md`, `qa-checklist.md`를 읽는다.
2. 입력이 Figma 링크면 `get_metadata`로 섹션·프레임 이름을, `get_design_context`로 장별 텍스트·색·폰트 크기를 뽑는다(`figma-design-to-code` 가이드 로드 후). PNG면 직접 보고 읽는다. JSON 스펙이면 `scripts/render_carousel.py`로 렌더해서 본다.
3. 아래 다섯 축으로 점검한다. 각 항목은 **장 번호 + 원문 인용 + 걸린 규칙 + 수정안** 네 요소를 갖춘다.
   - **Hook/Story**: 표지가 면접관 질문·속마음·실제 상황에서 시작하는가, 한 장에 메시지 하나인가, 7P 역할 흐름(질문→약한 답→이유→프레임→실제 발화→주의→워크시트)이 끊기지 않는가, 직전 콘텐츠와 레이아웃(사진 표지/3칸 카드/Before·After) 반복인가.
   - **Fact/Safety**: 단정·보장·공포 표현, 근거 없는 기출·수치, 언론 해석↔공식 발표 혼동, 오래된 공고의 현행 표기, NCS 예시의 기출 포장, 가상 예시 표시(※) 누락, 출처 캡션 누락, 민감 정보 공개 유도, 없는 성과 창작 권유.
   - **Product/Offer**: 기능명 공식 표기, 가격·할인율·기간·기존 고객 안내, 무료 조건(Workspace·유형별/계정별 1회), 선착순 문구, 미배포 기능, 제품 노출 위치(P1~P3 없음), Main CTA 1개.
   - **Design**: 캔버스 비율 통일, 포인트 블루 1종, 기업 CI는 포인트만, 헤드라인 2행(표지 3행)·본문 ≥ 34px·면책 ≥ 21px, 마진 64~80, 페이지 번호 "0N / 0M" 전 장, 브랜드 마크 위치, 캡처 고지 문구, `CareerMizing` 철자, 템플릿 복제 잔여물(다른 기업명·이전 캐러셀 카피·"DART 공시 기반 " 같은 미완 문장).
   - **Caption**: 유형별 구조, 첫 줄 훅, URL 미삽입(프로필/댓글 동선), 해시태그 4~8개 + `#커리어마이징`, 본문과 모순 없음, 기존 고객 안내(프로모션).
4. 한국어 자연스러움: 번역투·접속사 남발·사무적 개념어·교과서 문장을 짚고 "행동이 보이는 말"로 바꿔 쓴다.
5. 결과를 아래 형식으로 낸다. 확인할 수 없는 사실(현재 가격, 기능 배포 상태, 내부 수치)은 **"확인 필요"**로 남기고 추정하지 않는다.

## 출력 형식

```txt
[검수 결과] 승인 / 부분 수정 / 재작업
핵심 한 줄: (가장 큰 문제 1개)

P1: "원문 인용" → 걸린 규칙(brand-voice §8 단정 금지) → 수정안: "…"
P3: …
CTA: …
캡션: …
디자인: …

확인 필요(최대 3개): 1) … 2) … 3) …
통과 항목: Hook / Story / Fact / Product / Design / Caption 중 통과한 축
```

수정안은 그 자리에서 바로 쓸 수 있는 완성 문장으로 준다. 요청이 "고쳐줘"면 수정된 전체 카피(또는 수정된 JSON 스펙)를 함께 돌려주고, 필요하면 `careermizing-content`의 렌더러로 다시 렌더한다.
