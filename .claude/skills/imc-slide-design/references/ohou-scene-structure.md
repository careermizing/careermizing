# SCENE BOARD — 오늘의집 발표 전용 구조 (확정안)

GS 레퍼런스를 그대로 따르지 않고, 우리 주제(〈우리 집의 다음 장면〉)에서 구조를 뽑았다. GS 문법(걸친 캡슐, 큰 수치, 스포트라이트)은 **도구**로만 쓴다.
시안: `figma/specimen/scene.html` + `scene.css` → `png/S1~S6.png`, `_scene_contact.png`.

## 콘셉트
덱 전체를 **한 집의 장면이 바뀌어 가는 스토리보드**로 만든다. 발표 흐름(문제→원인→전략→실행→성과)을 5개의 SCENE으로 부르고, 시각 모티프 세 가지만 반복한다.

| 모티프 | 의미 | 쓰는 곳 |
|---|---|---|
| **뷰파인더 코너** (스카이블루 5px 코너 + REC 점) | "지금 이 장면을 보세요" | 챕터 오프너, BIG IDEA, 프로그램 시안, 핵심 컷 |
| **필름 스트립 + 장면 번호** (상단 5칸, 현재 칸만 길고 파랗게) | 발표 진행 위치 | 모든 본문 장표 좌상단 |
| **BEFORE / CUT / AFTER** (좌 웜그레이, 우 연블루, 가운데 CUT 컷선) | 단품 → 장면으로의 전환 | 전략 핵심(10P), 공간 변화 시안, 집들이 |

## 색·톤
- 배경: 따뜻한 페이퍼 `#F7F5F2` (리빙 톤, GS 회색과 구분). BEFORE 면 `#EDE7DF`.
- 포인트: 오늘의집 스카이블루 `#35C5F0`(면·선·코너), 글자용 딥블루 `#0E7FA5`(대비 확보), 연블루 `#DDF3FB`/`#EEF9FD`.
- 경고 빨강 `#E53935`은 이동·하락 수치 하나에만.
- 사진: 실제 방(집들이 톤) — 챕터 오프너와 BIG IDEA는 풀블리드 사진 + 하단 어두운 그라데이션.

## 5개 SCENE과 장표 흐름 (20분, 본문 22장 내외)

| SCENE | 이름 | 장표 | 오프너 질문 |
|---|---|---|---|
| — | 표지 · 요약 · INDEX | 3 | |
| 01 | 지금의 장면 (문제) | 오프너 + 01~05P | 오늘의집에서 찾았는데, 결제는 왜 다른 곳에서? |
| 02 | 장면 뒤의 이유 (원인) | 오프너 + 06~09P (+장벽 결론) | 왜 다른 곳에서 사고, 언제 오늘의집을 고를까? |
| 03 | 다음 장면의 조건 (전략) | 오프너 + 10~11P + BIG IDEA | 같은 상품이 어디에나 있을 때, 무엇을 팔아야 할까? |

| — | 마무리 · 부록 | 2 | |

## 장표 유형 (6 + 기존 도구)
- **S1 챕터 오프너**: 풀블리드 사진 + 뷰파인더 + 큰 질문(72B) + 필름 스트립. 각 SCENE 첫 장.
- **S2 근거 장표**: 필름 스트립 + 장면 번호 + 가운데 주장 제목 + 걸친 캡슐 카드 2개 + 큰 수치 + **장면 정리 바**(흰 바 + 왼쪽 파란 띠). 챕터 마지막 근거 장표에만 정리 바.
- **S3 장면 전환**: BEFORE / CUT / AFTER 분할. 전략 핵심 1~2장.
- **S4 BIG IDEA**: 사진 + 뷰파인더 + 104B 콘셉트 + CUT 1~4 유리 칩.
- **S5 IMC 스토리보드**: 4컷 뷰파인더 프레임 + 컷 번호 + 채널 칩 + 결제로 모이는 그라데이션 라인.
- **S6 프로그램 상세**: 장면 번호 `SCENE 04 · CUT n` + 키커 + 68B 이름 + 번호 카드 3개 + 우측 뷰파인더 안 폰 2대 + 성공 지표 핀.
- 그 외: 퍼널(T03), 장벽(T04, 다크), 스포트라이트(T07, 여정 다음 장), 비교표(T11), KPI 링(T10)은 `figma-gs-system.md` 컴포넌트를 장면 톤(페이퍼 배경·스카이블루)으로 바꿔 쓴다.

## 프로그램 이름 = 컷 이름
CUT 1 발견 **장면 사연함** → CUT 2 선택 **장면 밸런스게임** → CUT 3 구매 **장면 키트** → CUT 4 공유 **장면 집들이** (집들이가 다시 CUT 1로 순환).

## 리듬
오프너(사진·다크) → 근거 2~4장(페이퍼) → 정리 바 → 다음 오프너. 다크/사진 장표는 오프너·장벽·BIG IDEA·마무리에만. 같은 유형 연속 3장 금지(프로그램 CUT 1~4는 예외, 폰 위치 좌우 교대).
