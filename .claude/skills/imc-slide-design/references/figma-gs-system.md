# Figma 장표 시스템 — GS 에너지(ProSeed 2팀) 문법 고도화판

레퍼런스: ProSeed 2팀 「에너지플러스 2030 & 4050 사용자 이탈 방지 전략」 93p (본문 47p + 부록).
목적: 지금 장표가 **단조로운 이유**를 레퍼런스와 비교해 없애고, Figma에서 그대로 찍을 수 있는 수치로 정리한다.
시각 예시: `figma/specimen/png/T01~T12.png` (HTML 원본 `figma/specimen/templates.html`, 스타일 `kit.css`), 토큰: `figma/tokens.json`.

| 3 | 이미지 자리가 빈 점선 상자 | 기울인 폰 2~3대, 3D 캐릭터·굿즈·워치, 실제 화면 크롭 | 히어로 비주얼 |

## 5. 덱 리듬 규칙

1. **배경 시퀀스**: 표지(gradient) → 분석 구간 light 위주 → 문제 결론 **dark 1장** → 해결 시작 **gradient 섹션 커버** → 여정(light) → **스포트라이트(dim)** 반복(문제 하나당 1장) → 실행 구간은 **wash** 연속 → 성과 light → 마무리 gradient.
2. 같은 템플릿은 **연속 2장까지**(프로그램 상세 T08은 예외: 같은 틀 반복이 비교를 돕는다. 대신 폰 각도·배치를 좌우 교대).
3. **히어로 비주얼**(폰 클러스터·3D 오브젝트)이 4~6장마다 한 번 나온다.
4. 다크·dim 장표는 결론·전환점에만, 연속 2장까지.
5. 빨강은 덱 전체에서 하락 수치·화살표·핀 아이콘에만.
6. 스포트라이트는 직전 장표를 **복제해서** 만든다(새로 그리지 않는다) — 연속성이 설득력이다.

## 6. 이미지·에셋 규칙

- 폰: Figma Community iPhone 15/16 목업 컴포넌트 사용, 화면은 실제 캡처나 직접 그린 UI. 기울기는 목업 원근 변형(또는 렌더 PNG)으로 처리하고, 이미지를 마구 비틀지 않는다.
- 3D 아바타: Microsoft Fluent 3D Emoji(무료·MIT) 사람 이모지 또는 Memoji 스타일 일러스트 중 **한 가지 스타일로 통일**. 실존 인물 사진은 쓰지 않는다.
- 3D 오브젝트(소파·조명·박스 등)는 같은 렌더 톤(소프트 라이트, 틸 계열)으로 통일.
- 로고는 사실 확인된 채널 비교 표에서만. 브랜드 가이드 색 그대로.
- 모든 시안·목업에 `기획 시안` 표기(작게, 캡션 스타일).

## 8. Figma에서 만들 때 (Figma MCP 사용 시)

1. `figma-use` 스킬을 먼저 불러온 뒤(필수) `create_new_file` → `create_session`.
2. `tokens.json` → Variables(color·number) + Styles(gradient·effect·text) 등록.
3. C01~C17 컴포넌트 페이지(`🧩 Components`) 생성 → 템플릿 페이지(`🖼 Templates`)에 T01~T12 프레임 → 덱 페이지(`📑 Deck`)에 장표 배치.
4. HTML 시안(`figma/specimen/templates.html`)의 각 `section`이 프레임 하나이고, CSS 값은 Figma 속성으로 1:1 옮긴다(flex → Auto Layout, box-shadow → Drop shadow, backdrop-filter → Background blur, gradient → Gradient fill).
5. 장표 내용은 `references/ohou-figma-map.md`의 매핑을 따른다.
