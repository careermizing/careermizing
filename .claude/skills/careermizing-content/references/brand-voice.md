# 커리어마이징 카피 톤 가이드

Figma 캐러셀 약 440장의 실제 카피와 Notion 운영 문서(Hook 5원칙, 사람 말투 기준, 금지 표현)를 합쳐 정리했다.

## 1. 한 줄 요약

> **"실제 자기소개서를 다듬어주는 전문 컨설턴트가, 취준생 옆자리에서 말하듯"** — 내용은 깊고 냉정하게, 입구는 취준생의 고민처럼 쉽게. 과장·보장·공포 없이 근거와 행동으로 말한다.

타깃은 20대 이공계·대기업 준비 취준생이 1차, 직무 중심으로 취업을 준비하는 모든 취준생이 2차. 미디어 입구는 넓게, 본문 깊이는 엔지니어답게.

## 2. 어미와 문장

| 상황 | 어미 | 예 |
|---|---|---|
| 설명·조언(기본) | **해요체** "~해요 / ~예요 / ~돼요 / ~있어요" | "틀린 말은 아닌데, 누구나 비슷하게 말할 수 있어요." |
| 단정·근거·마무리 | 합쇼체 "~합니다 / ~입니다" | "직무가 달라지면 강점으로 꺼낼 경험도 달라집니다." |
| 행동 유도 | "~하세요 / ~해보세요 / ~두세요 / ~끝내세요" | "저장해두고, 내 경험으로 바꿔 말해보세요." |
| 기능 약속(기능 홍보) | "~드립니다 / ~드릴게요 / ~보여드립니다" | "뺀 경험엔 왜 뺐는지 이유를 보여드립니다." |
| 사실 나열·리스트 | **명사형 종결** | "자소서 대신 경험기술문항." / "각 500자." / "확인하고 붙여넣으면 끝." |
| 표지 훅·속마음 | 반말 질문형, 구어 | "아.. 직무 경험 없는데, 어떡하지?" / "근데 그냥 GPT 쓰면 되는 거 아니야?" / "알고 있어?" |
| 면접관 대사 | 존댓말 질문 | "그 조건이 틀어지면 어떤 문제가 생길까요?" |

규칙:
- 한 캐러셀 안에서 해요체를 기본으로 두고, 결론·근거 문장에서만 합쇼체로 힘을 준다. 두 어미가 한 장 안에 섞여도 된다(실제 사례 다수).
- 헤드라인은 2행 × 7~14자. 본문 1행 15~22자, 3행 구성. 한 장에 메시지 하나.
- 반말은 표지 훅(속마음)과 프로모션의 구어 한 줄("…진행하고 있다고??")에서만.
- 느낌표는 캐러셀당 1~2회(이벤트·공채 OPEN). 이모지는 표지/결론에 1개 이하(📌 🔥 ❌ 🥹 👀). 본문엔 기호만(→ ✓ × ▼ ① ②).
- 영문 약어는 그대로(JD, R&D, FSE, DART, BIW), 기업명은 구어 축약(하이닉스, 현대차, 엔솔)을 헤드라인에, 공식 표기(SK하이닉스, 현대자동차, LG에너지솔루션)를 칩·출처·캡션에.

## 3. 헤드라인 공식 (실제 사례)

| 공식 | 예 |
|---|---|
| 면접관 대사 + 속마음 | "채용 담당자 : / 다른 지원자랑 / 차별점이 뭔가요?" + "(속마음) 친구들은…착하다고 하던데?" |
| 오해 깨기 ❌ | "성장 과정 문항은 / '지금까지 있었던 일'을 쓰는 걸까요? ❌" / "서류 하나 붙었다고 / 그 회사 준비에 바로 올인하면 안 돼요 ❌" |
| 상황 선언 + 변화 | "올해 하이닉스 서류, / 완전히 달라졌습니다" / "이제 면접은 / 서류에 쓴 문장을 / 말로 증명하는 자리예요" |
| 조건 + 결과(2행 블루) | "가지고 있는 이력서 하나면, / 하이닉스 양식 그대로" / "찾은 행동을 답변으로 옮기면 / 이렇게 말할 수 있어요" |
| 질문 + 답 | "이 경험은 넣는 게 맞나? / 이번엔 포함 여부도 알려드릴게요." |
| 숫자 발견형 | "면접 복기 15건을 / 다 뜯어보니, / 꼬리질문은 / 딱 5가지였다" |
| 대조형 | "기출은 같아도, / 내 꼬리질문은 달라야 하니까." / "같은 경험인데 / 한 문장 차이로 달라져요" |
| 희소·시급 | "하이닉스 공채 기간엔, / 전부 무료입니다" / "26 하반기 공고, 지금 넘기면 다시 못볼 지도 몰라요" |
| 대체재 비판(완화형) | "질문만 뽑고 끝나면 / GPT와 크게 다를 필요가 없죠" / "아직도 AI에 "기업분석 해줘"만 쓴다면?" |
| 마지막 장 행동 지시 | "면접 전에, / 내 답변 3줄만 / 적어보세요." |

Hook 편집 5원칙(운영 문서 원문): ① 타깃 명확 — 누가 자기 일로 느낄 질문인가 ② 실제 상황 — 면접관의 말투 또는 취준생의 속마음에서 시작 ③ 긴장감 — 어려운 상황·결정 하나를 짧게 압축 ④ 정확성 — '무조건 탈락', '모든 면접관', '합격 보장' 금지 ⑤ 길이 — 큰 제목은 최대 1~2문장.

## 4. 강조 색·굵기에 들어가는 말

- **포인트 블루 span**: 결과/약속/해결("이렇게 말할 수 있어요", "행동 하나", "그때 한 행동", "밝힌 과제", "0원"). 헤드라인 2행 전체 또는 핵심 명사구.
- **Bold(본문색)**: 핵심 명사·수치·데이터 근거("면접 복기 데이터", "각 500자", "경험기술문항").
- **형광펜 `#FFF0A0`**: 결론 문장의 핵심구, 답변 예시의 행동 구절.
- **옐로(다크 프로모션)**: 번호, 할인율, 긴장 문장("③⑤를 비워 두는 순간, 거기서 평가가 갈립니다.").
- **레드**: BEFORE 라벨, "× 없는 실무 경험과 수치를 만들어내지 마세요." 경고 1회.
- **기업 CI 색 span**: "하이닉스가 원하는 역량이 무엇일까" 같은 '기업이 원하는 것' 1구절만.

## 5. 결론·면책·출처 문장 패턴

- 결론(하단 중앙): "'좋은 사람'보다 '이 일을 할 수 있는 근거'를 보여주세요." / "회사명은 짧게, 선택 기준은 분명하게." / "큰 약속 대신, 해본 일과 배울 기준을 연결하면 충분해요"
- 면책(답변 예시가 있는 장마다): "※ 이해를 돕기 위한 가상 답변입니다. 실제 합격 사례가 아닙니다." / "※ 실제로 한 일일 때만 답변에 사용하세요." / "※ 가상 예시 · 해당 활동을 실제로 한 경우에만 활용"
- 캡처 고지: "* 화면은 이해를 돕기 위한 예시입니다"
- 출처: "출처 : 핀터레스트" / "출처: 현대자동차 공식 발표(2026.08.26)" / "근거: 2026 Lam/AMAT 채용자료 · TEL 2026 상반기 채용" / "출처 : LG에너지솔루션 공식 직무소개 … 현재 채용공고가 아닌 직무 설명이며, 기업 · 직무별로 다를 수 있어요."
- 예상치: "최근 3개년 하반기 서류 접수 흐름을 기준으로 한 예상치입니다. 공식 공고 오픈 시 실제 일정으로 교체하세요."

**단정·과장**: '무조건 탈락', '모든 면접관', '합격 보장', '대기업 공통 기출'(근거 없을 때), '공식 4단계 합격법', "3문장 규칙이 있는 것처럼", 기업 의도 단정, 공백기 길이별 합격률 창작.

**프로모션**: 선착순(2026-11 이후 금지), 할인·합격 보장 과장, 정가 대비 오인 표기, 미배포 기능을 제공 중인 것처럼, '모든 면접 무제한 무료'(무료는 Workspace·유형별/계정별 1회 조건).

**가상 사례**: 가상 답변을 합격자 답변·실제 기출로 포장 금지, 반드시 '가상 예시' 표시. 실제 합격본·고객 원문 표시 금지.
**윤리**: 민감 정보(건강·가족사) 공개 유도, 없는 경험·수치·증빙 창작 권유, 팀원 비하, 타인 개인정보 AI 입력 유도.
**이미지**: 워터마크·무단 캡처·무단 인물 사진, 가짜 인증 배지.
**톤**: 사무적 개념어('쟁점/상호 우려/합의점 도출'), 교과서 문장('상대방의 사정을 이해하고 원활하게 소통'), 4단계 이론 설명, 과장된 가상 성공담, 제품을 1P부터 소개.

## 10. 한국어 자연스러움 체크

AI 티가 나는 패턴을 피한다: 번역투("~에 있어서", "~를 통해"), 접속사 남발("또한", "그리고"), 모든 문장 같은 길이, 불릿·이모지 과다, 영어 인용 과다. 한 장에 한 가지 질문만. 문장은 행동이 보이게("일정만 재촉했다 / 이야기를 해봤다 / 필요한 결과부터 받았다").
