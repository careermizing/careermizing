# 정기 취준 정보 콘텐츠 (취준팁 · 면접팁 · 정보성)

> 2026-11 기준: 디자인 바탕은 `../base-grammar.md`(모범 사례 「주변평가」·「공백기」)를 따르고, 아래 장별 표는 흐름 아이디어로만 쓴다. 장 구성은 `../components.md` §6 질문으로 정한다.

Figma 페이지 「하반기 정기 취준 정보 콘텐츠」(섹션 40여 개, 1080×1350)와 운영 SOP를 합쳤다. 하위 유형 셋은 **서사 구조가 다르다.**

## A. 면접팁 7P (가장 많이 만든 포맷, 2026-10 Published 다수)

**목적**: 저장·공유(Evergreen). 면접 질문 하나를 "왜 묻는지 → 흔한 답 → 개선 → 실제 발화 → 주의 → 워크시트"로 푼다.
**Layer**: 범용 취준 Pain(70%). 제품 노출은 P7에만.

| P | 역할 | 아키타입 | 카피 패턴 (실제 사례) |
|---|---|---|---|
| 1 | 면접관 질문 + 속마음 | `cover_typo`(다크 타이포) 또는 `cover_photo`(밈/인물 사진) | "채용 담당자 : / 다른 지원자랑 / 차별점이 뭔가요?" + "혹시 아셨나요? 이 질문은 장점을 묻는 게 아니에요." / 타이포형: eyebrow "채용 담당자 :" → 질문 → 훅 "'절대 안 그럴 겁니다'가 / 정답은 아닙니다." → 소형 "면접관이 보고 싶은 건 …에 가깝습니다." |
| 2 | 약한 답변·흔한 실수 | `text` + 인용 + 2카드(내 장점 / 직무 연결: 비어있음) 또는 손글씨 패널 + 오답 카드 2 | "틀린 말은 아닌데, / {누구나} 비슷하게 말할 수 있어요" + "많이 하는 답변" 라벨 + 인용 "저는 성실하고 책임감이 강합니다…" + 결론 "'좋은 사람'보다 '이 일을 할 수 있는 근거'를 보여주세요." |
| 3 | 면접관 의도 / 부족한 이유 / 꼬리질문 | `cards`(번호 리스트 01~03) · `chat` · 다이어그램 | "면접관이 이 질문으로 / 보고 싶은 건 3가지예요." → 01 기업의 이해 / 02 판단 / 03 연결(블루) |

| 6 | 예외·주의 | `cards`(크림 카드 ①②③ + 연블루 예시 카드 + × 경고) | "큰 성과를 / 약속할 필요는 없어요." + "× 없는 실무 경험과 수치를 만들어내지 마세요." + 결론 "큰 약속 대신, {해본 일과 배울 기준}을 연결하면 충분해요" |

변형:
- 6P(공백기): 타이포 표지 → 질문의 빈틈 → 3단계 타임라인 → 발화 스크립트 → 별도 사유 대응 → 워크시트. 크림 테마.
- 기술 질문 zip(10P): 표지 → 브릿지(외워간 답변 vs 실제 면접 질문 칩 3개) → 대화 흐름 → 준비할 3가지 → 공정 카드 ×4("공정은? / 뭘 관리할까? / 잘못되면?" + 핵심 용어 칩) → 답변 예시 → CTA(댓글 키워드).
- 연속 시리즈 네이밍: `[DRAFT] 20261021 / 면접팁 / 퇴사하고 싶어지면? (7P)`.

**직전 콘텐츠와 레이아웃 반복 회피**: 사진 표지 ↔ 타이포 표지, 3칸 카드 ↔ 표 ↔ 대화 카드, Before·After ↔ 필기형 워크시트를 번갈아 쓴다.

## B. 취준팁 (자소서·경험정리·운영법) 6~7P

**구조**: 공감(오해 깨기 ❌) → 정보 → 구조/질문 4개 → 예시(BEFORE/AFTER 또는 합격 자소서 발췌) → 매핑 표 → 홍보 1장 → CTA.

실제 사례 두 개:
- 「"직무 경험이 없다"는 착각」: 사진 표지("아.. 직무 경험 없는데, 어떡하지?" / "불안한 당신을 위한 / 현직자의 경험정리 Tip") → 체크리스트 5행 + 네이비 박스 → 스텝 로우 4(관찰·문제·행동·결과) + 블루 결론 박스 → 질문 4개 번호 리스트 + 프로그레스 바 → BEFORE/AFTER 2단(핵심 강점 0/4 vs 4/4) → JD↔경험 매핑 표 + 좌측 보더 인용 → 홍보("커리어마이징에서는 / 이 모든 걸 무료로 할 수 있다고?") → 라디얼 CTA("댓글에 "경험정리" 남기면"). 라이트 에디토리얼(헤어라인 + 풋터 "다음 → …").
- 「성장과정 문항 작성법 · D-1」: 사진 표지("인사팀이 감탄하는 / 성장과정 작성법 / 알고 있어?" + "삼성 D-1인데 모르는 사람 100명 넘겠지?") → 오해 ❌ + 공식 박스("행동 기준 → 배경/사례 → 적용 or 포부") + 밈 2장 → 질문 카드 4개(세로 레일) → 체크리스트 3(형성/확장/통합 pill) → 합격 자소서 발췌 카드(서론: 판단기준/배경/포부) → 삼성 프로모션 CTA.

헤드라인에 ❌ 오해 깨기, 서브에 "No!! …하세요" 같은 구어 허용. 밈은 공감용으로만, 출처 캡션 필수.

## C. 정보성 (채용 일정·전형 변화·자격증·AI 역량) 6~7P

**목적**: 저장. **구조**: 지금 일어난 일 → 핵심 사실(기준일·대상) → 누가 해당 → 지원자 관점 의미 → 확인/준비할 행동 → 원문 확인·CTA. 약한 답변·개선 예시 구조는 불필요.

정보성 필수 표기: 자료 기준 날짜, 적용 대상, 공식 출처(디자인·캡션 모두). 미확정 일정은 "예상"으로 표시하고 각주를 단다. 마지막 두 장은 홍보 1장(`promo_brand`) + 라디얼 CTA(댓글 키워드 "자소서"/"기업분석").

## D. 기획안 → 카피 작업 순서 (이 유형 공통)

1. Brief: Layer / Persona / Moment / Pain·Question / One Sentence Insight / Hook 3안(A 최종, B 공감형, C 저장형) / Evidence Pack(출처+열람일) / Carousel Flow(장당 한 문장) / Proof(가상 예시 표시) / CTA 1개 / Success Metric.
2. 장별 카피: 메인(헤드라인 2행) / 서브 / 본문 / 하단 결론 / Visual 가이드 / 면책.
3. Fact-check 블록: 단정 금지 항목, 출처 범위, 가상 예시 표시 위치.
4. 캡션 + Story 투표 + Threads 한 문단.
5. 디자인 스펙: 아키타입 지정 → `render_carousel.py`로 미리보기 → 검수 요청 템플릿.
