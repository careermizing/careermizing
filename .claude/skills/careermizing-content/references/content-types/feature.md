# 기능 홍보 콘텐츠 (프로덕트 업데이트 공지)

Figma 페이지 「하반기 기능 홍보 콘텐츠」: 이력서 기능 오픈(8장), 면접 1~5(5장), 기업분석 리뉴얼(6장). 모두 1080×1440. **커리어마이징 자체 브랜드 톤(블루)** + 서비스 UI 캡처가 핵심 비주얼. 운영 원칙상 "제품 홍보 콘텐츠를 별도로 많이 만들지 않고, 취준 문제 해결 과정에서 제품이 등장"해야 하므로 월 20건 중 3건 수준. 직접 홍보형 게시는 CEO 최종 승인 후.

## 1. 구조 3종

### A. 기능 오픈 공지 (8장, 라이트 본문) — 이력서 기능
| P | 아키타입 | 카피 |
|---|---|---|
| 1 | 다크 네이비 표지 + UI 캡처(우측 넘침) + 플로팅 카드 | 칩 "NEW · 8/20 OPEN" → "하이닉스 이력서, / 한 번에 끝내세요" → "기업별 맞춤 이력서 기능 출시 기념 / {하이닉스 공채 단 7일간 무료로 제공됩니다.}(시안)" |
| 2 | `text` 문제 제기 | 칩 "하이닉스 공채" → "올해 하이닉스 서류, / {완전히 달라졌습니다}" → 사실 나열(명사형) + 공감 + 기업색 1구절 → 하이라이트 바 "역량을 드러내기 어려운 분들을 위해 저희가 만들었습니다 →" |
| 3~6 | `feature` 기능 ①~④ | 칩 "기능 ①" → "가지고 있는 이력서 하나면, / {하이닉스 양식 그대로}" → 본문 3행 → 이미지/기능 카드(칩 행 → 제목 → 회색 박스 → 출처 칩) → "* 화면은 이해를 돕기 위한 예시입니다". 기능③은 포함(솔리드)/제외(점선) 대비 + "없는 경험·수치는 지어내지 않습니다." |
| 7 | `benefit` | 칩 "공채 기간 무료 이벤트" → "하이닉스 공채 기간엔, / {전부 무료입니다}" → 기간 → 가격 행 3(300크레딧→0원 …) → 조건 → "커리어마이징과 함께 지금 바로 시작하세요." |
| 8 | 다크 CTA | 칩 "Coming Soon" → 대형 캡처 → "26 상 하이닉스 합격자 350명이 사용한 / 바로 그 서비스, / 댓글에 "이력서" 남기면 / 오픈 즉시 사용할 수 있는 링크 드릴게요." + Raleway Thin 워터마크 |

### B. 기능 리뉴얼 안내 (5장, 라이트 블루 그라디언트, 중앙정렬) — 면접
풀 로고 표지("기업별 맞춤형 / 이력서 기능 출시" + 날짜 "26.08.20") → 본문 3장(로고 아이콘 → 헤드라인 Bold 54 2행 → 목업 900×590 + 플로팅 카드 → 설명 3행 36px) → 마무리("새로워진 면접 기능, / 지금 바로 시작해보세요" + "프로필 링크에서 커리어마이징 접속하고 / 경험정리부터 자기소개서, 면접 준비까지 끝내세요." + 혜택 "면접 기능 리뉴얼 기념 / 전 계정 500 크레딧 증정").
본문 장 = "헤드라인(약속) → 화면 → 3행 설명(근거→기능→효용)". 예: "23-25년 대기업 면접 복기본 기반 질문으로 / 실전처럼 준비하세요" → "최근 {면접 복기 데이터}를 바탕으로 / 직무와 기업에 맞는 질문을 만들고, / {실제 면접 흐름}에 가까운 방식으로 답변을 준비하세요."

### C. 리뉴얼 + 프로모션 (6장, 포토 다크) — 기업분석
사진 표지("여러분의 성공적인 취준을 위한 / 커리어마이징 / 기업분석 기능 리뉴얼") → 개선점 1~3(흰 칩 "기업분석 기능 개선 1" → Inter Bold 56 → 캡처 r10 + blur 페이드) → 혜택 2단 글래스 카드(BENEFIT 01 가격 / 02 분석집) → 라디얼 CTA("26 상반기 대기업 / 합격자 1,000명이 극찬한 / 대기업 특화 취준 AI, 커리어마이징").

## 2. 디자인 규칙

- 포인트: `#0033FF`(피처 블루) 또는 `#0D5DF1`(프로덕트). 2행 헤드라인의 2행이 블루 약속문.
- 라이트 본문 그리드: 패딩 88/96, 콘텐츠 904, 칩 h63 px30 py14 r999, 헤드라인 SUIT ExtraBold 72/87.84/-2%, 본문 Pretendard Medium 38/60.8 `#3C4352`, 카드 r28 보더 2px `#E7ECF4` 그림자 `0 24 30 rgba(13,35,110,.12)` 패딩 48/44, 내부 박스 `#F0F3F8` r20.
- 다크 표지/CTA: 라디얼 `#16308F→#070D28`, 캡처 r20, 표지 캡처는 좌 54 우측 넘침(991까지), CTA 캡처 좌우 33 거의 풀블리드.
- 캡처 프레이밍: design-system.md §7. 캡처가 있는 라이트 카드마다 고지 문구.
- 로고: 포토 테마 매 장 좌하단 (82,1341); 라이트 블루 테마 상단 중앙(표지/마무리 풀 로고, 본문 아이콘만); 라이트 본문 로고 없음, CTA만 워터마크.
- 페이지 번호 없음(이 유형).

## 3. 카피 규칙

- 기능명은 공식 명칭(brand-voice.md §9). "경험기술문항"으로 통일. 요금은 "크레딧", 플랜은 "Max Plan/Max 플랜".
- 약속 어미 "~드립니다/~드릴게요", 사실은 명사형, 행동 유도 "~하세요".
- 정직성 선언을 포함한다: "없는 경험·수치는 지어내지 않습니다." "실제 지원서 필드와 1:1 — 확인하고 붙여넣으면 끝."
- 사회적 증거는 CTA에만, 수치는 현행 확인("합격자 350명", "1,000명").
- 무료 조건은 정확히: "하이닉스 공채 단 7일간", "횟수 제한 없음 · 경험기술문항 작성은 가입 시 제공되는 크레딧으로 무료 체험 가능", "전 계정 500 크레딧 증정". 미배포 기능을 제공 중처럼 쓰지 않는다 (CEO 결정 2026-10-16).
- 이력서 CTA는 "댓글에 "이력서" 남기면 오픈 즉시 사용할 수 있는 링크 드릴게요"(댓글), 면접은 "프로필 링크에서 … 끝내세요"(프로필).

## 4. 자주 생긴 실수 (Figma에서 관찰)

- 템플릿 복제 후 카피 미교체(「면접 기능 업데이트」 섹션이 기업분석 카피 그대로, 면접 1 표지가 이력서 카피). 새 캐러셀을 만들 땐 모든 장의 칩·헤드라인·출처를 교체했는지 확인.
- 헤드라인 1행만 입력된 미완 장("DART 공시 기반 ").
- "Careermizing" 소문자 칩.
- 서비스 UI 내부 오타("맟춤 목록")가 캡처에 그대로 노출 → 캡처 전 UI 텍스트 확인.
