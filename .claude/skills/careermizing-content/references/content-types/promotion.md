# 프로모션 콘텐츠

Figma 페이지 「하반기 프로모션 홍보 콘텐츠」(현대차·SK하이닉스 합불조사·삼성·기아·CJ·장비사·11월 면접·면접 기능 리뉴얼)에서 추출. 1080×1440가 대부분, 최신(11월 면접)은 1440 다크 그라디언트.

## 1. 하위 유형과 구조

| 유형 | 장수 | 흐름 | 사례 |
|---|---|---|---|
| **기업 공채 × 자료 프로모션** | 8~10 | 공채 확대 훅(사진 표지) → 왜 그런가(채용설명회 인용) → 전략 1 → 계열사/직무별 전략 카드 ×4 ×2장 → 혜택 1(전략집 3권 부채꼴) → 혜택 2(분석본 2×2) → 선착순/플랜 혜택 카드 3 → 추가 혜택 2단(BENEFIT 01/02) → CTA | CJ, 기아, 삼성 그룹사 |
| **산업 인사이트 × PASS 상품** | 8 | Data 훅 → 실제 채용 사례(근거 카드 3) → 왜 Data인가(과거/지금 스텝 + INSIGHT) → 3사 차이(비교 카드 + INSIGHT) → 같은 경험 다른 어필(가상 예시 + 3 row) → PASS 소개(문서 커버 3) → 구성(혜택 4 + "MAX 플랜 구매자 전용") → CTA(패널 + 버튼 "댓글 "장비사"") | 외국계 장비사 v2 |

공통 리듬: **훅(사진/숫자) → 공감·근거 2~3장 → 차별점·비교 → 상품/혜택 → CTA**. 다크 테마 비중이 높고, 혜택 장에서만 옐로 포인트.

## 2. 디자인 특징

- 표지: 사진 + 오버레이 + Pretendard ExtraBold 105 2행 + Medium 56 설명. 또는 다크 그라디언트 + 태그 pill + Black 96 4행(숫자 훅).
- 본문 다크 카드: `#0E1833` 보더 `#1F386B` r18~22, 번호 옐로 `#FFC70D` + 제목 흰 Bold 25~36 + 설명 `#B2C2DB` + 우측 키워드 `#8CB8FF`. 또는 `#131D3C` 보더 2px `#334A85` r24(11월 면접).
- 좌측 액센트 바 카드(장비사): 6px `#2E75F2`, 라벨 시안 `#1FB8FF`.
- INSIGHT 카드: 옐로 보더 `#FABF0D` + 라벨 "INSIGHT" `#FFC70D`.
- 혜택 박스: 보더 3px `#FFCC01` r22, 제목 Bold 32 `#EBF2FF` + 디바이더 + 불릿 2열.
- 상품 커버: 270×480 r18 `#081129` 보더 `#406BC7`, 좌측 8px 컬러 바(`#4278FF`/`#24D1AD`/`#FF6338`), "BONUS 01" 라벨.
- 가격: 정가 취소선(`#979797`) + 할인가 Bold 52 + "50%" 배지(`#FFE249`). 기간 "9/1(화) - 9/7(월)".
- CTA: 라디얼 네이비(캡처 카드 + 증거 헤드라인 + 민트 바 + 댓글 키워드) 또는 다크 패널(`#0E1833` 보더 `#1AA3FF`) + 솔리드 버튼 `#2E75F2` r37 "댓글 "장비사"" + 태그라인 "대기업·딥테크 취준 AI  CareerMizing".

## 3. 카피 톤

- 구어 훅: "왜 CJ는 4년만에 / 역대급 채용을 할까?", "Max 플랜 최대 40%할인까지 진행하고 있다고??", "장비사 준비, / 회사명만 바꿔 쓰지 마세요"
- 근거 문장은 회사·수치·출처 명시: "램리서치 Data Analytics FSE 신설부터 / AMAT CE의 digital analytics 요구까지" + "근거: 2026 Lam/AMAT 채용자료 · TEL 2026 상반기 채용"
- 반론 처리: "맞아요. / 예상 질문 몇 개 만드는 건 / GPT로도 됩니다." → "대신 차이는 / 질문의 '출발점'부터 시작됩니다."
- 상품 설명은 '많이 준다'가 아니라 '흐름': "핵심은 자료를 많이 주는 게 아닙니다. / 3사를 같은 표에서 비교하고 → 내 경험을 회사별로 다르게 쓰고 → 마감 직전까지 점검하는 한 흐름으로 구성했습니다."
- CTA: "댓글에 "{키워드}" 남기면 / {사업 전략집 + 참여 링크} 보내드릴게요." 키워드는 기업명/주제 한 단어("CJ", "장비사", "면접", "🔥").

## 4. 2026-11 이후 반드시 지킬 가격·혜택 규칙

- **선착순 문구 금지**, 합격 보장·과장 할인 금지. (과거 "선착순 100명 한정"은 현행 규칙 위반 → 재사용 금지)
- Max 가격은 게시 당일 가격 페이지 기준. 11월 면접 프로모션 승인 기준: Max 1개월 49,000원 유지 · Max 6개월 176,400원(월 정가 49,000×6 = 294,000원 대비 40%). "기존 6개월 판매가 대비"로 오인되지 않게 표기.
- 기존 활성 Max 고객은 추가 결제 없이 혜택 제공 — **캡션에 안내**.
- 무료 기능은 조건 명시: "무료 모의면접 1회"(계정당 1회), 질문 생성은 Workspace·유형별 최초 1회. "모든 면접 무제한 무료" 금지.
- 전략집만 파는 행사로 설명하지 않는다(Max 이용 가치 먼저, 전략집은 추가 혜택).
- 추가 자료 약속은 확정 전 고지 금지. 수치 카드(예: 경총 조사 67.6%)는 원문 확인 전 삭제.
- 프로모션 메시지 분리: 무료 기능 광고는 이용을, Max 구매 광고는 구매를 설득.
