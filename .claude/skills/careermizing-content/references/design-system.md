# 커리어마이징 캐러셀 디자인 시스템

Figma 「26 하반기 인스타그램 콘텐츠」 파일(4개 페이지, 약 440장)에서 역설계한 규칙이다. 수치는 Figma 원본 px/hex. 기계가 읽는 값은 `assets/tokens.json`에 같은 내용이 있다.

## 목차
1. 캔버스와 비율
2. 테마 5종 (언제 무엇을 쓰나)
3. 컬러
4. 타이포그래피
5. 레이아웃 그리드
6. 로고와 브랜드 표기
7. 사진·이미지·목업 규칙
8. 테마별 "재현용 치트시트"

---

## 1. 캔버스와 비율

| 규격 | 용도 | 비고 |
|---|---|---|
| **1080×1350 (4:5)** | 2026-10 이후 정기 콘텐츠 표준: 취준팁·면접팁·정보성·D-3 시리즈 | 새 콘텐츠의 기본값 |
| 1080×1440 (3:4) | 기업 공채 오픈 캐러셀, 프로모션(CJ·장비사·면접 리뉴얼), 기능 홍보(이력서·기업분석) | 구형 템플릿. 1440으로 만들 땐 상하 45px은 안전영역 밖으로 취급 |

새 콘텐츠는 1350을 기본으로 하고, 기존 1440 시리즈를 이어갈 때만 1440을 쓴다. 한 캐러셀 안에서 비율을 섞지 않는다(과거 혼용 사례는 실수에 가깝다).

## 2. 테마 5종

콘텐츠는 아래 다섯 테마의 조합으로 만들어진다. **한 캐러셀은 보통 "표지 테마 1 + 본문 테마 1 + CTA 테마 1"**으로 구성된다.

| 테마 | 배경 | 주 용도 | 대표 시리즈 |
|---|---|---|---|
| **A. 포토 표지** | 사진 풀블리드 + 검정 세로 그라디언트 | 표지(모든 유형), 기업 공채 본문 | 공채 오픈, 면접팁 표지(밈/인물 사진), 정보성 표지 |
| **B. 라이트 에디토리얼** | `#FFFFFF` / `#F7F9FD` / `#F2F4F8` | 본문 대부분: 취준팁·면접팁·정보성·D-3·기능 설명 | 면접팁 7P 시리즈, 경험정리 Tip, 이력서 기능 오픈 |
| **C. 네이비 다크** | `#081327` / `#060B1B` / 그라디언트 `#0B1530→#050A1A` | 타이포 표지, 데이터 리스트(공채 일정·자격증), 프로모션 본문, 마지막 워크시트 CTA | 면접팁 타이포 표지·P7, 공채 일정, 11월 면접 프로모션, 면접 리뉴얼 |
| **D. 라디얼 CTA** | 라디얼 `#16308F→#11246A→#0C1745→#070D28` | 서비스 CTA 슬라이드(캡처 카드 + 사회적 증거 + 댓글 CTA) | 거의 모든 1440 캐러셀의 마지막 장 |
| **E. 크림 에디토리얼** | `#FAF7F1` + 코랄 `#FC6B57` 소량 | "직전 콘텐츠와 레이아웃 반복 회피"용 변형 | 공백기 면접팁 |

선택 규칙:
- 취준팁·면접팁 → 표지 A 또는 C(타이포) / 본문 B / 마지막 C(워크시트+버튼).
- 정보성(일정·자격증 등 데이터형) → 표지 A / 본문 C(다크 리스트) 또는 B(표·타임라인) / 홍보 1장 + CTA D.
- 기업별 공채 → 표지 A(접수기간+기업명) / 본문 A(다크 텍스트)·B(문서형 분석) / 홍보 + CTA D.
- 프로모션 → 표지 A 또는 C / 본문 C(카드 리스트, 옐로 포인트) / CTA C(버튼형) 또는 D.
- 기능 홍보 → 표지 C 또는 D(UI 캡처) / 본문 B(기능 카드) 또는 라이트 블루 그라디언트(중앙정렬 목업) / CTA D.
- 같은 주 안에서 "사진 표지 / 3칸 카드 / Before·After"를 연속 반복하지 않는다 (운영 문서 지침).

### 3-5. 사진 오버레이
