# 기본 문법 — 반드시 지키는 것 (고정)

커리어마이징 정기 콘텐츠(취준팁·면접팁·정보성)와 그 문법을 빌리는 프로모션·기능 소개의 **공통 바탕**이다. 기준점은 대표가 모범 사례로 지정한 두 편이다.

- 「주변에서는 본인을 어떻게 평가하나요?」 Figma 978:1640 (8P, 포인트 `#0D5DF1`)
- 「공백기가 있네요?」 [REDESIGN] Figma 871:332 (6P, 포인트 `#2F5CE0`)

> **고정과 유동의 경계.** 이 문서의 수치(글자 크기·굵기·색·여백·톤)는 지킨다. 반대로 어떤 컴포넌트를 쓰고 몇 장으로 어떤 순서로 풀지는 내용에 맞게 정한다(`components.md` §흐름 설계). 두 모범 사례의 장 순서를 그대로 베끼는 것이 목표가 아니다. 더 좋은 구성이 있으면 그걸 쓰되, 아래 문법 안에서 만든다.

## 1. 캔버스·배경

- 1080×1350. 본문 배경은 **흰색 `#FFFFFF`**. 회색·크림 배경은 쓰지 않는다(카드 안쪽 면에만 `#F2F4F8`·`#F3F7FE`·`#F7F8FA`).
- 다크는 두 군데에만: 사진 표지, 마지막 행동 유도 장(`#071022`) 또는 서비스 장(`#0E1530`).
- 한 캐러셀 안에서 포인트 블루는 하나만: `#2F5CE0`(기본) 또는 `#0D5DF1`.

## 3. 배치

```
(75,65)   브랜드 에셋: 아이콘 35 + "CareerMizing" Raleway SemiBold 26.2 그라디언트 #323F91→#356FB6
y 151~168 헤드라인 2행 (중앙형은 x 중앙, 좌측형은 x 76)
y ~340    서브 한 줄
y 380~1090 본문 컴포넌트 영역 (좌우 72, 폭 936)
y 1120~1250 결론 (중앙, 2행 이내)
y ~1275   면책 (필요할 때만)
```

- 좌우 여백 72~76, 콘텐츠 폭 928~936. 카드 테두리 3px `#E3E8F0`, 라운드 28~36. 강조 카드는 테두리만 포인트 블루로.
- 페이지 번호는 **넣지 않는다**(마지막 다크 장에만 `06 / 06` 허용).
- 한 장의 구성은 **헤드라인 → (서브) → 본문 컴포넌트 1~2개 → 결론**. 결론은 거의 모든 본문 장에 있다.
- 사진 표지: 사진 풀블리드 + 검정 딤(.2~.45) + 하단 페이드, 좌상단 다크 로고 (65~75, 65~90), 헤드라인 좌하단.

## 4. 카피톤 (바뀌지 않는 부분)

- **헤드라인 2행 공식**: 1행이 상황·질문(검정), 2행이 답·관점(블루). 예: "난감한 이 질문 / **어떻게 답변하고 있나요?**", "찾은 행동을 답변으로 옮기면 / **이렇게 말할 수 있어요**", "공백기 답변, / 이 순서로 정리해보세요."
- **해요체 기본**, 끝을 "~요 / ~세요"로 부드럽게. 결론은 한 문장 판단: "흔한 칭찬이어도 괜찮아요. **그 말을 들은 행동**이 있으면 내 답이 돼요."
- **실제 말투**로 시작: 면접관 대사("채용 담당자 : 공백기가 있네요 뭐하셨어요?"), 속마음("(속마음) 밥먹고 자고 드라마 봤는데요?"), 오답("오답: '착하다는 말을 많이 들었습니다ㅎㅎ (뻘쭘)'").
- 다음 장으로 넘기는 한 줄을 결론에 둔다: "뭐가 다른 지 알려드릴게요", "면접관: 그래서...어떤 준비를 하셨는데요?"
- 짧게. 서브는 한 줄, 카드 설명도 한 줄. 설명이 두 줄을 넘으면 장을 나눈다.
- 금지: 단정·보장·공포("무조건", "모든 면접관", "합격 보장"), 사무적 개념어, 교과서 문장. 가상 답변은 "※ 이해를 돕기 위한 답변입니다" 표기. (상세: `brand-voice.md`)

## 5. 이미지

- 짤·사진을 적극적으로 쓴다(표지 풀블리드, 본문 600×431 r28). 역할은 공감·비교·실전 예시 중 하나.
- 자리만 잡을 땐 점선 상자 + "이미지 자리 (사진·짤로 교체)"로 남기고, 검수 메모에 교체 필요를 적는다.
- 출처 캡션("출처 : 핀터레스트") 필수.
