# 컴포넌트 인벤토리와 슬라이드 아키타입

Figma에서 반복 등장한 UI 패턴을 "컴포넌트"로, 슬라이드 단위의 조합을 "아키타입"으로 정리했다. 렌더러(`scripts/render_carousel.py`)의 슬라이드 `type` 이름과 1:1로 맞춰 두었으니, 기획 단계에서 아키타입 이름으로 바로 구성안을 쓰면 된다.

## 2. 슬라이드 아키타입

렌더러 `type` 값과 역할. 각 아키타입은 "무엇이 들어가는가 → 순서 → 비고".

| type | 아키타입 | 구성 (위→아래) |
|---|---|---|
| `cover_photo` | 포토 표지 | 사진 + 오버레이 → (좌상단 로고) → [서브(위) 42~60 Regular/SemiBold "아.. 직무 경험 없는데, 어떡하지?"] → 헤드라인 Black 86~110 2~3행 (하단 정렬, y≈700~980) → [서브(아래) 45 SemiBold] → 출처 캡션 |
| `cover_typo` | 타이포 표지(다크) | 브랜드 마크 + 페이지 → eyebrow "채용 담당자 :" → 질문 Black 74~82 3행 → 액센트 바 → 훅 Bold 40 2행 → 소형 Medium 28 2행 |
| `cover_promo` | 프로모션/공채 표지 | 사진 + 오버레이 → (접수기간 SemiBold 50 .7) → 헤드라인 ExtraBold 105 2행(1행 기업명 포인트색) → 설명 Medium 56 → (배지 "무료 모의면접 1회") → 로고 + 출처 |
| `text` | 텍스트 본문 | 브랜드 마크 → 헤드라인 → 서브 → 본문 단락 1~3 (또는 이미지) → 결론 → 면책 |
| `cards` | 카드 리스트 | 헤드라인 → 서브 → 번호 카드 2~5개 → 결론/하이라이트 박스 |
| `steps` | 스텝/프로세스 | 헤드라인 → 서브 → 번호 사각/원 + 라벨 row 4~5개 → (무료 바) |
| `compare` | 2단 비교 | 헤드라인 → 좌 카드(칩+제목+불릿) | 우 카드(칩+제목+결과 pill) → 결론 |
| `before_after` | BEFORE/AFTER 세로 | 헤드라인 → BEFORE 박스(취소선) → AFTER 카드(태그 pill + 문단 + 디바이더) → 결론 |
| `answer` | 실제 답변 예시 | 헤드라인 "그럼 면접에서는 / 이렇게 말할 수 있어요" → 서브 "○○ 지원자 · 가상 답변" → 답변 카드(3문단, 우측 태그) → 결론 "📌 저장해두고…" → 면책 |
| `chat` | 대화 흐름 | 타이틀 "면접" → 지원자/면접관 카드 교차 4개 → 결론 |
| `table` | 표 | 헤드라인 → 서브 → 표(헤더 + 행) → 결론 |
| `datalist` | 다크 데이터 리스트 | 로고 → 헤드라인 64 → 서브 → 행 N개(날짜|기업|메모|상태) → (강조 테두리) → 각주 |
| `checklist` | 체크리스트 | 헤드라인 → 체크 행 5개 → 네이비 결론 박스 |
| `worksheet` | 빈칸 워크시트 | 헤드라인 → 카드 3개("1 라벨 / 문장 ____ / 예)") → 결론 |
| `feature` | 기능 설명 | 칩 "기능 ①" → 헤드라인 72(2행 블루) → 본문 3행 → 캡처/기능 카드 → "* 화면은 이해를 돕기 위한 예시입니다" |
| `benefit` | 혜택/가격 | 칩 → 헤드라인 → 기간 라인 → 가격 행 3개(취소선→0원) → 조건 안내 → 마무리 2문장 |
| `promo_cards` | 다크 프로모션 카드 | 태그 pill → 헤드라인 Black 72~96 → 카드(번호 옐로 + 제목 + 설명) 2~3 → 옐로 강조 문장 + 캡션 출처 |
| `promo_cta` | 프로모션 CTA(다크) | 칩 "무료로 시작" → 헤드라인 → 체크 리스트 4 → CTA 버튼 → 서브 → 로고 |
| `cta_worksheet` | 마지막 장(워크시트 + 버튼) | 브랜드 마크 + "07 / 07" → 액센트 바 → 헤드라인 "면접 전에, / 내 답변 3줄만 / 적어보세요." → 워크시트 카드 → 제품 동선 한 줄 "경험정리 → JD 기반 경험 선택 → 면접 연습" → 버튼 |
| `cta_radial` | 라디얼 CTA(1440) | 캡슐 → 캡처 카드 → 헤드라인(증거 2행 + 그라디언트 1행) → 민트 바 + "댓글에 "키워드" 남기면 / … 링크 드릴게요." |
| `promo_brand` | 홍보 1장(포토 다크) | 칩 "커리어마이징" → Inter Bold 56 2행 "커리어마이징에서는 / 이 모든 걸 무료로 할 수 있다고?" → 서브 → 로고 |
| `service_placeholder` | 서비스 장(캡처 자리) | 캡슐 → 캡처 자리 → 헤드라인 "1.5만 건의 대기업 합격자료로 만들어진 / 대기업 특화 취준 AI, 커리어마이징" → 세로바 + 문장 |
| `note` | 검수 메모 | 크림 bg, 메모 + 캡션 초안 + UTM |

| P | 취준팁/면접팁 (7P) | 정보성 (6~7P) | 기업 공채 (6P) | 프로모션 (8P) | 기능 홍보 (6~8P) |
