# 램리서치 FSE 면접 대비본
### 장비사 실제 면접 패턴으로 재구성한 모의 면접

*커리어마이징 · 2026년 10월 1일 기준 · MAX 플랜 구매자 전용 자료*

---

## 이 자료에 대하여

장비사 현장 엔지니어 면접은 회사가 달라도 흐름이 비슷합니다. **자소서 경험을 끝까지 검증하는 꼬리질문, 경험 속 장비의 원리, 고객 상황 대응, 장비 트러블슈팅 케이스, 로열티와 영어**입니다.

이 자료는 「실제 장비사 면접 복기본」에서 확인한 질문 패턴을 **램리서치 FSE 전형, 이번 회차 자기소개서 5문항, 램리서치 대표 장비**에 맞춰 모의 면접으로 재구성했습니다.

| 파트 | 내용 |
|---|---|
| **PART 1. 램리서치 FSE 면접 구조** | 전형, 면접에서 확인하는 것, 장비사 면접 공통 패턴 |
| **PART 2. 모의 면접 ①: 자소서 기반 경험 검증** | 5문항에서 출발하는 꼬리질문 흐름과 답변 포인트 |
| **PART 3. 모의 면접 ②: 식각 장비 트러블슈팅 케이스** | 도체 식각 챔버 PM 후 이상, 극저온 식각 챔버 온도 이상 |
| **PART 4. 모의 면접 ③: 고객 상황 · 인성 · 로열티 · 영어** | 고객 Fab 상황 질문과 인성 질문 |
| **PART 5. 장비 질문 꼬리질문 체인** | 램리서치 장비에서 출발해 원리까지 내려가는 질문 |
| **PART 6. 면접 전 최종 점검** | 체크리스트 |

### 꼭 읽어 주세요

- **이 자료는 램리서치 면접 복기가 아닙니다.** 다른 외국계 장비사(ASML, TEL)의 실제 현장 엔지니어 면접 복기에서 확인한 질문 패턴을, 램리서치 FSE의 전형·문항·장비에 맞춰 **재구성한 모의 면접**입니다. 실제 램리서치 면접에서 같은 질문이 나온다는 뜻이 아닙니다.
- **모의 면접의 지원자 경험은 가상입니다.** 「합격 데이터 기반 3사 지원 전략」의 사례(가상)를 그대로 가져와, 자소서와 면접이 어떻게 이어지는지 보여 줍니다.
- **전형은 최근 회차 기준입니다.** 이번 회차 공고와 안내 메일로 다시 확인하세요.

# PART 1. 램리서치 FSE 면접 구조

## 1-1. 전형 (최근 회차 기준)

| 단계 | 내용 | 준비 포인트 |
|---|---|---|
| 서류 | 자기소개서 5문항 × 400자 | 면접 꼬리질문의 출발점 |
| 온라인 인성검사 | — | 응답의 일관성 |
| **Job Café** | 직무 소개·소통 성격의 단계 | 회사·직무에 대한 질문 1~2개 준비 |
| **1차 면접** | 실무 중심 | 경험 검증, 장비 기초, 영어 1분 자기소개 |
| **2차 면접** | 임원·인사 중심 | 로열티, 조직 적응, 근무 조건 |
| 건강검진 → 최종 승인 | — | — |

이번 회차는 인턴 단계 없이 **정규직 직접 채용**입니다. 예전에는 인턴 기간에 현장에서 하던 검증을 이제 면접이 맡기 때문에, **경험 검증 꼬리질문이 더 깊어질 가능성**이 큽니다.

## 1-2. 면접에서 확인하는 것

이번 자기소개서 5문항 중 4문항이 "사람"을 묻습니다. 면접도 같은 축으로 움직인다고 보고 준비하세요.

| 확인하려는 것 | 출발 문항 | 면접에서의 모습 |
|---|---|---|
| **하드웨어를 부품 단위로 좁히는가** | ① 하드웨어 실습 | "그 부품이 원인이라는 걸 어떻게 확신했나?" |
| **Fab 상주를 버틸 체력·멘탈** | ② 힘들었던 경험 | "교대·긴급 대응이 이어지면 어떻게 관리하나?" |
| **처음 만나는 고객과 신뢰를 쌓는가** | ③ 신뢰 | "고객 엔지니어가 신입을 믿지 않으면?" |
| **한 가지를 오래 붙잡는가** | ④ 몰입 | "왜 그렇게 오래 했나? 무엇이 달라졌나?" |
| **바뀌는 절차를 받아들이는가** | ⑤ 새 시스템·절차 | "데이터 기반 정비, 코봇이 들어오면?" |

## 1-3. 장비사 실제 면접에서 확인한 공통 패턴

「실제 장비사 면접 복기본」의 다섯 가지 패턴은 램리서치 면접에도 그대로 적용됩니다.

1. **경험은 검증됩니다.** 역할 → 근거 → 판단 → 기간 → 원리 → 재발 방지 순서로 7개 이상의 꼬리질문이 이어졌습니다.
2. **장비 질문은 원리까지 내려갑니다.** 경험 속 장비의 작동 원리를 묻습니다.
3. **고객 상황 질문이 나옵니다.** 화난 고객, 매뉴얼 이상의 요구, 부품 교체를 꺼리는 고객.
4. **회사에 대한 확신을 확인합니다.** "둘 다 붙으면?", "원하는 장비가 아니면?"
5. **영어는 갑자기 나옵니다.** 램리서치는 영어 1분 자기소개를 반드시 준비하세요.

# PART 2. 모의 면접 ①: 자소서 기반 경험 검증

> **가상 지원자 설정**: 학부 연구실에서 PECVD를 다룬 지원자. 자소서 ①번에 "히터 열전대 접촉 불량을 찾아 증착 균일도를 되살린 경험"(지원 전략 사례 A), ②·③번에 "물류센터 야간 아르바이트"(사례 E)를 썼습니다.

## 2-1. ① 하드웨어 실습에서 출발하는 꼬리질문

| # | 예상 질문 | 답변 포인트 | 면접관이 확인하는 것 |
|---|---|---|---|
| 1 | 그 장비 문제는 혼자 해결했나? | 원인 추적과 조치는 직접, 조치 전에 선배와 교수님께 계획을 공유 | **본인 역할** |
| 2 | 샤워헤드, MFC, 히터 중 왜 그 순서로 의심했나? | 레시피 변경이 없었고 가장자리만 얇아지는 패턴 → 유량보다 온도 쪽을 우선 의심 | **판단 순서의 근거** |
| 3 | MFC가 정상이라는 건 어떻게 확인했나? | 설정값과 실측 유량 비교 | **측정 방법** |
| 4 | 외곽 존이 6도 낮다는 건 어디서 봤나? 그 차이가 두께에 왜 영향을 주나? | 히터 로그. 증착 속도는 온도에 민감해서 가장자리 반응이 느려짐 | **원리 이해** |
| 5 | 열전대 접촉 불량은 왜 생겼다고 보나? | 반복 가열·냉각으로 인한 체결 느슨해짐 추정 | **원인 추론** |
| 6 | 고친 뒤 정상이라는 건 어떻게 판단했나? | 10장 연속 증착에서 편차가 원래 수준으로 돌아옴 | **검증 기준** |
| 7 | 재발 방지는? 점검 주기는 왜 그렇게 정했나? | 점검표에 존별 온도 편차 항목 추가. 주기는 사용 빈도 기준 | **표준화** |
| 8 | 그 경험이 고객 Fab의 식각 장비에서는 어떻게 쓰이나? | 증상 → 원인 후보 → 측정 → 조치 → 검증 순서는 장비가 달라도 같다 | **직무 연결** |

> 💡 실제 장비사 면접에서도 "매뉴얼을 보고 원인을 어떻게 확신했나?", "정상 주기에서도 그 문제가 생기는 이유는?"처럼 **경험 속 장비의 원리**를 끝까지 물었습니다. 자소서에 쓴 장비는 원리를 1분 안에 설명할 수 있어야 합니다.

# PART 3. 모의 면접 ②: 식각 장비 트러블슈팅 케이스

> 실제 장비사 면접에서는 영어로 된 고객 상황·장비 구조도·로그를 40분 동안 분석하고 action plan을 발표하는 형식이 나왔습니다. 램리서치 면접에서 같은 형식이 나온다는 뜻은 아니지만, **장비 이상을 어떤 순서로 좁히는지**는 1차 면접의 상황 질문으로 충분히 나올 수 있습니다. 아래 케이스로 생각하는 순서를 연습하세요.

## 3-1. 케이스 A: 도체 식각 챔버, PM 후 가장자리 식각률 저하

**상황**
> 고객 Fab의 도체 식각 챔버에서 정기 PM(에지 링·라이너 교체, 챔버 세정)을 마치고 재가동했습니다. 모니터 웨이퍼에서 **웨이퍼 가장자리의 식각률이 중심보다 눈에 띄게 낮고, 파티클도 평소보다 많습니다.** 고객은 생산 재개가 급하다며 빠른 조치를 요구합니다.

**주어진 데이터 (가정)**
- 식각률 맵: 가장자리 저하, 중심은 정상
- 챔버 압력, 가스 유량: 설정값과 일치
- RF 반사 전력: PM 전보다 약간 증가
- 정전척(ESC) 후면 헬륨 유량: 한 구간이 평소보다 높음

**모범 접근**

| 단계 | 할 일 | 말하는 법 |
|---|---|---|
| ① 상황 정리 | PM 직후 발생 → PM에서 바뀐 것부터 의심 | "PM 전에는 정상이었으므로, PM에서 손댄 부품과 절차부터 확인하겠습니다" |
| ② 증상 정의 | 가장자리 식각률 저하 + 파티클 증가 + RF 반사 증가 + 헬륨 유량 이상 | "증상이 네 가지인데, 한 원인에서 나왔는지 따로인지 구분하겠습니다" |
| ③ 가설 | (a) 에지 링 장착 높이·체결 불량 → 가장자리 플라즈마 분포 변화 (b) ESC 후면 헬륨 누설 → 가장자리 웨이퍼 온도 불균일 (c) PM 후 시즈닝 부족 → 파티클 (d) RF 정합 변화 | 원인 후보를 2~4개로 |
| ④ 분리 진단 | PM 기록과 체결 토크 확인 → 에지 링 장착 상태 점검 → 헬륨 누설 점검 → RF 정합 확인 → 시즈닝 웨이퍼 추가 후 재측정 | **비용·시간이 적은 확인부터** |
| ⑤ 조치 | 원인별 조치: 재장착, 실링 부품 교체, 시즈닝 추가, 정합 조정 | 부품이 필요하면 재고·위치를 먼저 확인해 고객과 동료에게 공유 |
| ⑥ 검증 | 모니터 웨이퍼로 식각률 균일도·파티클이 사양 안에 드는지 확인 | "사양 안에 들어온 것을 확인한 뒤 생산 재개를 요청드리겠습니다" |
| ⑦ 고객 공유·에스컬레이션 | 예상 시간과 진행 상황을 약속한 시간마다 공유. 공정 조건 문제로 보이면 공정 엔지니어(FPE)와 본사 지원 요청 | "현장에서 해결되지 않으면 공정 엔지니어와 함께 보겠습니다" |

**예상 꼬리질문**
- 에지 링이 가장자리 식각률에 왜 영향을 주나? → 소모되면서 높이가 달라지면 가장자리의 플라즈마 분포가 바뀐다
- ESC 후면에 헬륨을 왜 흘리나? → 웨이퍼와 척 사이 열전달을 높여 웨이퍼 온도를 고르게 유지
- PM 후 시즈닝은 왜 하나? → 세정 직후 챔버 벽 상태를 안정화해 공정 재현성을 확보하고 파티클을 줄임
- RF 반사 전력이 늘면 무엇이 문제인가? → 플라즈마로 전달되는 전력이 줄고 정합이 틀어졌다는 신호
- 고객이 "검증은 생략하고 바로 돌리자"고 하면? → 사양 미달 상태로 생산하면 수율 손실이 더 커진다는 점을 근거와 함께 설명하고, 검증 시간을 최소화하는 방법을 제시
- 체결 토크는 왜 기록하나? → 같은 문제가 재발했을 때 비교 기준이 됨

## 3-2. 케이스 B: 극저온 식각 챔버, 척 온도 이상 알람

**상황**
> 3D NAND 채널홀을 식각하는 극저온 식각 챔버에서 **웨이퍼 척 온도가 목표보다 높게 유지된다**는 알람이 반복됩니다. 같은 시점부터 채널홀 아래쪽 지름이 커지는(형상이 휘는) 결과가 나옵니다.

**모범 접근**
1. **온도 이상과 형상 이상의 연결 확인**: 극저온 식각은 낮은 온도에서 측벽 반응을 억제해 곧은 구멍을 만듭니다. 온도가 오르면 측벽이 더 깎여 형상이 휠 수 있습니다.
2. **가설**: 냉각 장치(칠러) 출력 저하, 냉매 유량 감소(배관 막힘·밸브 이상), 척 온도 센서 오류, 웨이퍼-척 열전달 저하(후면 헬륨 압력 이상)
3. **분리 진단**: 칠러 설정값과 실제 출력 비교 → 냉매 공급·회수 온도와 유량 확인 → 센서 값을 독립 측정과 비교 → 후면 헬륨 압력·누설 확인
4. **조치·검증**: 원인 부품 조치 후 척 온도 안정화 확인 → 모니터 웨이퍼 단면으로 형상 확인
5. **공유**: 형상 이상이 난 기간의 웨이퍼 목록을 고객에게 공유해 영향 범위를 판단하게 함

**예상 꼬리질문**
- 극저온 식각이 왜 깊고 곧은 구멍에 유리한가?
- 칠러는 정상인데 척 온도만 높다면 어디를 보겠나?
- 센서 오류인지 실제 온도 이상인지 어떻게 구분하나?
- 이상이 난 기간에 생산된 웨이퍼는 어떻게 처리해야 하나? (고객과 공정 엔지니어 판단 영역임을 알고 정보를 정확히 제공)

## 3-3. 케이스를 풀 때의 원칙

- **"마지막으로 바뀐 것"부터 의심하세요.** PM, 부품 교체, 레시피 변경, 업그레이드 직후의 이상은 그 작업에서 출발합니다.
- **증상이 여러 개면 한 원인인지 따로인지 먼저 구분하세요.**

- **검증 기준을 말하세요.** "고쳤다"가 아니라 "사양 안에 들어온 것을 확인했다"가 끝입니다.

# PART 5. 장비 질문 꼬리질문 체인

면접의 장비 질문은 한 문장으로 끝나지 않습니다. 아래처럼 **원리까지 3~4단계** 내려간다고 보고 준비하세요. 장비별 원리는 「Equipment Tech Map」 PART 1에 있습니다.

**체인 1. "램리서치 장비 중 아는 것을 말해 보세요"**
1. → Vantex와 Lam Cryo 3.0으로 3D NAND 채널홀을 식각합니다
2. → 채널홀 식각은 왜 어렵나? (수백 단을 10μm급 깊이로 위아래 편차 없이)
3. → 극저온이 왜 도움이 되나? (측벽 반응 억제로 깊고 곧게)
4. → FSE로서 극저온 장비에서 추가로 신경 쓸 것은? (냉각·열관리 시스템)

**체인 2. "도체 식각과 유전체 식각은 무엇이 다른가요?"**
1. → 도체는 선택비·프로파일, 유전체는 고종횡비가 핵심
2. → 선택비가 무엇인가?
3. → Akara의 DirectDrive는 무엇을 개선했나? (플라즈마 응답 속도)
4. → 그게 GAA에서 왜 중요한가?

**체인 3. "PM은 무엇이고 왜 하나요?"**
1. → 소모품 교체·세정으로 장비 상태를 사양 안에 유지
2. → 식각 챔버에서 소모되는 부품은? (에지 링, 라이너, 샤워헤드 등)
3. → PM 후 바로 생산하지 않는 이유는? (시즈닝, 검증)
4. → PM 주기는 무엇으로 정하나? (RF 시간, 웨이퍼 수, 상태 데이터)

**체인 4. "왜 텅스텐에서 몰리브덴으로 바꾸나요?"**
1. → 미세 선폭에서 저항이 낮고 배리어가 필요 없음
2. → ALTUS Halo는 무엇이 처음인가? (Mo ALD 양산 장비)
3. → ALD는 CVD와 무엇이 다른가? (원자층 단위, 단차 피복성)
4. → TEL은 같은 시장에 어떻게 들어오나? (배치 퍼니스의 경제성)

**체인 5. "자동화가 늘면 FSE는 필요 없어지지 않나요?"**
1. → Dextro 코봇, Equipment Intelligence가 반복 정비와 보정을 맡음
2. → 그럼 FSE는 무엇을 하나? (데이터로 문제를 미리 좁히고 결과를 검증)
3. → DA FSE는 무엇이 다른가?
4. → 본인은 그 변화에 어떻게 대비했나? (⑤번 자소서 경험과 연결)
