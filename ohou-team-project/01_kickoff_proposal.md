## 3. 캠페인 후보 3개 (오늘 1개 선택)

| | **A. 새집 D-60 (추천)** | B. 보이는 그대로 산다 | C. 우리집 리셋 챌린지 |
|---|---|---|---|
| 풀려는 문제 | 이사·신혼 고객이 시공·대형 가구 결정 단계에서 경쟁사로 빠져나감 | 콘텐츠에서 본 상품을 29CM·쿠팡 등에서 구매 (쇼루밍) | MAU 정체, 집들이 업로드 감소 |
| 타깃 | 3개월 내 이사·입주 예정 신혼부부, 첫 독립 2030 | 콘텐츠는 많이 보지만 구매 전환이 낮은 이용자 | 이용이 뜸해진 기존 이용자 |
| 빅 아이디어 | 입주일 등록 → D-60 플래너 + 무료 실측·견적 비교 + 번들 + D+30 집들이 리워드 | 집들이 사진 속 공간을 "방 통째로" 담는 번들 + 단독가 | 비포·애프터 UGC 챌린지 + 크리에이터 |
| 핵심 지표 | 등록 고객 90일 고관여 구매 전환율 | 콘텐츠 → 구매 전환율, 객단가 | MAU, UGC 업로드 수 |
| 근거 확보 | 🟢 시공 투자 공식 보도, 혼인·이사 통계, 설문 | 🟡 설문·관찰로만 증명 | 🟢 MAU 공개 |
| 차별성 | 🟢 오늘의집만 가능한 조합 | 🟡 커머스 기능 개선에 가까움 | 🔴 흔한 UGC 캠페인 |
| PT 임팩트 | 🟢 D-day 목업, 스토리텔링 쉬움 | 🟢 시연이 직관적 | 🟡 문제와 연결 약함 |
| **종합** | **추천** | 대안 (A의 구매 단계로 흡수) | 비추천 (A의 공유 단계로 흡수) |

**A를 추천하는 이유**
1. 회사가 "시공 성장을 위해 단기 손익을 포기했다"고 밝힘 → 이 문제를 풀면 회사에 가장 큰 도움이 된다는 논리가 공식 자료로 받쳐짐
2. 이사는 51년 만에 최저, 혼인은 7년 만에 최다 → "새로 집을 꾸미는 순간"이 귀해져 한 명도 놓치면 안 된다는 논리가 시장 분석에서 나옴
3. B(번들)와 C(UGC)를 A의 단계별 장치로 흡수할 수 있음

## 4. 추천 캠페인 상세: 「새집 D-60」

### 4-1. 문제 → 인사이트 → 아이디어

| 단계 | 내용 |
|---|---|
| 문제 (한 문장) | 오늘의집은 이사·신혼 고객이 가장 큰 돈을 쓰는 시공·대형 가구 결정 단계에서 그들을 경쟁사에 넘겨주고 있다. |
| 고객 인사이트 (가설) | 영감은 오늘의집에서 얻지만, 몇백만 원짜리 시공은 직접 보고 비교할 수 있는 곳에서 결정한다 → 문제는 관심이 아니라 **결정의 불안** |
| 빅 아이디어 | 입주일이라는 **마감일**을 오늘의집에 맡기게 한다. 날짜가 등록되는 순간 "구경하는 앱"이 "우리 집 프로젝트 매니저"가 된다. |
| 핵심 카피 | 구경은 충분히 했어요. 이제 우리 집 차례. |

### 4-2. 캠페인 구조 (고객 여정 6단계)

| 단계 | 장치 | 문제 해결 포인트 |
|---|---|---|
| ① 인지 | 웨딩·이사 접점 제휴, 크리에이터 시리즈 "D-60 우리 집 만들기" | 이사가 정해진 사람을 정확히 찾음 |
| ② 탐색 | 앱 내 D-60 플래너: 평형·예산·스타일별 집들이 추천, 주차별 체크리스트 | 막연한 영감을 할 일 목록으로 |
| ③ 결정 ★ | 무료 실측 + 견적 3곳 비교, 오프하우스·라운지 상담 예약, 시공 보증 | 핵심 이탈 구간, 결정 불안 해소 |
| ④ 구매 | 시공 계약 고객 "방 통째로" 가구·가전 번들 (후보 B 흡수) | 시공 → 대형 가구까지 묶음 |
| ⑤ 입주 | 입주 주간 소품 추천, 설치 일정 알림 | 재구매 연결 |
| ⑥ 공유 | D+30 우리 집 공개 집들이 리워드 (후보 C 흡수) | 다음 고객의 콘텐츠가 됨 |

### 4-3. 채널

| 채널 | 역할 | 선택 이유 |
|---|---|---|
| 앱 CRM | 기존 이용자 중 이사 예정자 전환 | 월 300만 명 이상이 쓰는 앱, 가장 싸고 정확 |
| 네이버 검색광고 | 고의도 검색 | 시공 고민하는 사람이 실제로 검색하는 곳 |
| 크리에이터 | 신혼·자취 집들이 시리즈 | 영감 → 실행 스토리텔링 |
| 제휴 (웨딩·이사·부동산) | 신규 Life Event 고객 | 이사 시점을 아는 파트너 |
| 오프라인 | 상담·체험 | 고관여 결정은 직접 상담 필요 |

쓰지 않는 것: TV·옥외. 문제는 인지도가 아니라 전환.
